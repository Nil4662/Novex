## ✅ پیش‌نیازها

قبل از شروع باید **Node.js** روی کامپیوتر شما نصب باشد.

1. به سایت [nodejs.org](https://nodejs.org) بروید.
2. نسخه **LTS** (نسخه پایدار) را دانلود و نصب کنید.
3. برای اطمینان از نصب، در ترمینال این دستور را بزنید:
   ```bash
   node --version
   ```
   باید شماره نسخه (مثلاً `v20.x.x`) نمایش داده شود.

> نیازی به نصب جداگانه npm نیست؛ همراه با Node.js نصب می‌شود.

## 🚀 راه‌اندازی در VS Code

1. **پوشه پروژه را باز کنید:**
   - VS Code را باز کنید.
   - از منوی `File` گزینه `Open Folder` را انتخاب کنید.
   - پوشه‌ای که فایل `package.json` در آن قرار دارد را انتخاب کنید. ⚠️ **یک فایل را باز نکنید؛ کل پوشه پروژه را باز کنید.**

2. **ترمینال داخلی را باز کنید:**
   - از منوی `Terminal` گزینه `New Terminal` را انتخاب کنید یا کلید `Ctrl + ` (بک‌تیک) را بزنید.

3. **نیازهای پروژه را نصب کنید:**
   ```bash
   npm install
   ```
   این کار ممکن است چند دقیقه طول بکشد. صبر کنید تا نصب کامل شود.

## 🖼️ تعویض تصویر غذا

تصاویر در پوشه `public/images` و زیرپوشه‌های آن قرار دارند:

```
public/images/
├── hero/        ← تصاویر بخش هیرو
├── categories/  ← تصاویر دسته‌بندی‌ها
├── iranian/     ← تصاویر غذاهای ایرانی
├── fast-food/   ← تصاویر فست‌فود
├── seafood/     ← تصاویر غذاهای دریایی
├── sushi/       ← تصاویر سوشی
└── icons/       ← آیکون‌ها و تصویر جایگزین
```

### مثال: تعویض تصویر قرمه سبزی

1. پوشه `public/images/iranian/` را باز کنید.
2. فایل JPG دلخواه خود را در این پوشه قرار دهید.
3. نام فایل را دقیقاً به `ghormeh-sabzi.jpg` تغییر دهید.
4. اگر فایل قبلی وجود دارد، آن را جایگزین کنید.
5. وب‌سایت را در مرورگر رفرش کنید.

تصویر جدید به‌صورت خودکار نمایش داده می‌شود. هیچ تغییری در کد لازم نیست! 🎉

> 📖 راهنمای کامل تصاویر را در فایل [IMAGE_GUIDE.md](./IMAGE_GUIDE.md) ببینید.

> اگر تصویری وجود نداشته باشد، به‌جای علامت تصویر شکسته، یک تصویر جایگزین زیبا نمایش داده می‌شود.

## ➕ افزودن غذای جدید

فایل `src/data/foods.ts` را باز کنید. یک بلوک جدید به آرایه `FOODS` اضافه کنید:

```ts
{
  id: 'my-new-food',                 // شناسه یکتا (انگلیسی، با خط تیره)
  nameFa: 'نام فارسی غذا',
  nameEn: 'English Name',
  descFa: 'توضیح فارسی...',
  descEn: 'English description...',
  category: 'iranian',               // iranian | fast-food | seafood
  subcategory: 'rice-stews',         // زیردسته مناسب
  priceToman: 300000,                // قیمت نمایشی به تومان
  priceUsd: 9,                        // قیمت نمایشی به دلار
  image: 'iranian/my-new-food.jpg',  // مسیر تصویر (نام فایل)
  ingredientsFa: ['ماده ۱', 'ماده ۲'],
  ingredientsEn: ['Item 1', 'Item 2'],
  protein: 'meat',                   // meat | chicken | seafood | vegetarian
  popular: true,                      // اختیاری: محبوب
},
```

سپس تصویر با نام `my-new-food.jpg` را در پوشه `public/images/iranian/` قرار دهید.

## 💰 تغییر قیمت غذا

در فایل `src/data/foods.ts`، غذای مورد نظر را پیدا کنید و مقادیر `priceToman` و `priceUsd` را تغییر دهید:

```ts
priceToman: 350000,  // قیمت به تومان
priceUsd: 10.5,       // قیمت به دلار
```

> این قیمت‌ها نمایشی هستند و با نرخ ارز تبدیل نمی‌شوند.

---

## ✏️ ویرایش توضیحات

برای ویرایش متن هر غذا، در فایل `src/data/foods.ts` فیلدهای `descFa` و `descEn` و `ingredientsFa` و `ingredientsEn` را ویرایش کنید.

برای ویرایش متون رابط کاربری (دکمه‌ها، عنوان‌ها، پیام‌ها)، فایل `src/i18n/translations.ts` را باز کنید. تمام متون فارسی و انگلیسی در یک مکان متمرکز هستند.

---

## 🏷️ تغییر نام برند

فایل `src/config.ts` را باز کنید و مقادیر `BRAND` را ویرایش کنید:

```ts
export const BRAND = {
  nameFa: 'نام فارسی جدید',
  nameEn: 'New English Name',
  taglineFa: 'شعار فارسی جدید',
  taglineEn: 'New English Tagline',
};
```

---

## 🎨 تغییر پالت رنگ

در فایل `src/config.ts` مقادیر `COLORS` را تغییر دهید. همچنین برای تغییر استایل‌های پیشرفته، در فایل `src/styles/global.css` متغیرهای CSS در بخش `:root` را ویرایش کنید:

```css
:root {
  --strong-orange: #FF6B00;
  --soft-orange: #FFB36B;
  --red: #E53935;
  --yellow: #FFC928;
}
```

## 🔧 رفع خطاهای رایج

| خطا | راه‌حل |
|------|--------|
| `npm: command not found` | Node.js را نصب کنید. |
| `vite: command not found` | `npm install` را اجرا کنید. |
| صفحه سفید نمایش داده می‌شود | کنسول مرورگر (F12) را چک کنید؛ احتمالاً مسیر تصویر اشتباه است. |
| پورت ۵۱۷۳ اشغال است | سرور قبلی را با `Ctrl + C` متوقف کنید یا پورت دیگری استفاده کنید. |
| تغییرات دیده نمی‌شود | مرورگر را رفرش کنید (`Ctrl + R`). |
| خطای TypeScript | مطمئن شوید کاماها و براکت‌ها در `foods.ts` درست هستند. |
