# ZAGROS — وب‌سایت رستوران چند‌آشپزخانه (نمونه‌کار نمایشی)

یک پروژهٔ کامل **React + TypeScript + Vite** برای یک رستوران خیالی با چهار آشپزخانه:
ایرانی، فست‌فود، دریایی و نوشیدنی.

> **این سایت یک نمونه‌کار خیالی است.** همهٔ قیمت‌ها، آدرس‌ها، ساعت کاری و دکمه‌های خرید
> نمایشی هستند و هیچ سفارشی ثبت نمی‌شود. هیچ درگاه پرداختی به پروژه متصل نیست.

---

## ۱. این پروژه چه دارد؟

- صفحهٔ اصلی با ۱۳ بخش: بنر اصلی، دسته‌بندی‌ها، فهرست دسته، معرفی، سه بنر تبلیغاتی،
  محبوب‌ترین‌ها، بنر میانی، آشپزخانه، مفهوم پروژه، کمبوها، خبرنامه، گالری و تماس.
- **بنر اصلی پویا**: با انتخاب هر دسته، تصویر، تیتر، توضیح و دکمه به‌صورت نرم عوض می‌شود.
- **۱۸۱ آیتم منو** در چهار دسته با نام، توضیح، مواد اولیه، آلرژن و قیمت دوزبانه.
- صفحهٔ منوی کامل با جست‌وجوی فارسی/انگلیسی و فیلترهای دسته، زیرشاخه، قیمت و نوع غذا.
- مودال جزئیات هر غذا (تصویر، مواد اولیه، سرو، آلرژن، پیشنهادهای مرتبط).
- دوزبانگی کامل: فارسی (راست‌به‌چپ) و انگلیسی (چپ‌به‌راست) با ذخیرهٔ انتخاب زبان.
- صفحهٔ «خرید نمایشی» در مسیر `/demo-purchase`.
- تصاویر: هر تصویر یک مسیر و یک نام فایل مشخص دارد؛ اگر فایل نباشد، یک **قاب طراحی‌شده**
  با نام فایل مورد انتظار نمایش داده می‌شود (هیچ آیکون شکسته‌ای نمی‌بینید).
- طراحی واکنش‌گرا از ۳۲۰ پیکسل موبایل تا ۱۹۲۰ پیکسل مانیتور.
- احترام به تنظیم «کاهش حرکت» سیستم (`prefers-reduced-motion`).

## ۲. پیش‌نیاز: نصب Node.js

1. به [nodejs.org](https://nodejs.org) بروید.
2. نسخهٔ **LTS** را دانلود و نصب کنید (نسخهٔ ۱۸ یا بالاتر؛ پیشنهاد: ۲۰ یا ۲۲).
3. برای اطمینان، ترمینال (یا CMD) را باز کنید و بنویسید:

```bash
node -v
npm -v
```

اگر شمارهٔ نسخه چاپ شد، نصب درست است.

---

## ۳. باز کردن پروژه در Visual Studio Code

1. VS Code را باز کنید.
2. از منوی **File → Open Folder** پوشهٔ پروژه (همان پوشه‌ای که `package.json` در آن است) را انتخاب کنید.
3. اگر پرسید «Do you trust the authors?» گزینهٔ **Yes, I trust the authors** را بزنید.

---

## ۴. باز کردن ترمینال در VS Code

از منوی **Terminal → New Terminal** (یا کلید میان‌بر <kbd>Ctrl</kbd> + <kbd>`</kbd>).
ترمینال پایین پنجره باز می‌شود و باید در مسیر پوشهٔ پروژه باشد.

---

## ۵. نصب وابستگی‌ها

در ترمینال بنویسید:

```bash
npm install
```

این دستور پوشهٔ `node_modules` را می‌سازد و ممکن است ۱ تا ۳ دقیقه طول بکشد.
اگر خطای شبکه داد، دوباره اجرا کنید.

---

## ۶. اجرای سایت

```bash
npm run dev
```

در ترمینال چیزی شبیه این می‌بینید:

```
➜  Local:   http://localhost:3000/
```

---

## ۷. باز کردن سایت در مرورگر

آدرس زیر را در مرورگر باز کنید:

```
http://localhost:3000
```

با هر تغییر در فایل‌ها، صفحه به‌صورت خودکار به‌روز می‌شود (Hot Reload).

---

## ۸. توقف سرور

در ترمینال کلیدهای <kbd>Ctrl</kbd> + <kbd>C</kbd> را بزنید (در مک: <kbd>Control</kbd> + <kbd>C</kbd>).
برای اجرای دوباره، فقط `npm run dev` را تکرار کنید.

---

## ۹. جایگزینی تصاویر

همهٔ تصاویر داخل پوشهٔ `public/images` قرار می‌گیرند و نام فایل هر تصویر از قبل مشخص است.
برای جایگزینی:

1. پوشهٔ مربوطه را باز کنید (مثلاً `public/images/iranian`).
2. فایل JPG خود را داخل آن کپی کنید.
3. نام فایل را دقیقاً برابر نام فایل مورد انتظار بگذارید (مثلاً `ghormeh-sabzi.jpg`).
4. صفحه را رفرش کنید.

**راهنمای کامل با فهرست همهٔ ۱۸۱ نام فایل در فایل [`IMAGE_GUIDE.md`](./IMAGE_GUIDE.md) است.**

---

## ۱۰. افزودن غذای جدید

۱. فایل دستهٔ مربوطه را باز کنید:

| دسته | فایل |
| --- | --- |
| ایرانی | `src/data/iranian.ts` |
| فست‌فود | `src/data/fastfood.ts` |
| دریایی و سوشی | `src/data/seafood.ts` |
| نوشیدنی | `src/data/drinks.ts` |

۲. یک آبجکت مثل نمونهٔ زیر به آرایه اضافه کنید:

```ts
{
  id: 'saffron-rice-cake', sub: 'stew', en: 'Saffron Rice Cake', fa: 'ته‌چین زعفرانی',
  descEn: 'Crisp saffron rice cake with yogurt.', descFa: 'ته‌چین تُرد زعفرانی با ماست.',
  toman: 320000, usd: 8.9,
  ingEn: 'Rice, yogurt, saffron, egg', ingFa: 'برنج، ماست، زعفران، تخم‌مرغ',
  serving: '450 g', tags: ['vegetarian'], allergens: ['dairy', 'egg'], featured: false,
},
```

۳. نام فایل تصویر به‌صورت خودکار از `id` ساخته می‌شود؛ یعنی تصویر باید
`public/images/iranian/saffron-rice-cake.jpg` باشد.

**نکته‌ها:**

- `sub` باید یکی از شناسه‌های زیرشاخه‌های همان دسته باشد
  (`stew` / `kebab` / `local` برای ایرانی، `pizza` / `burger` / `sandwich` / `chicken` برای فست‌فود،
  `fish` / `sushi` برای دریایی، `traditional` / `soft` / `juice` / `hot` برای نوشیدنی).
- `tags` می‌تواند شامل `meat`، `chicken`، `seafood`، `vegetarian`، `vegan`، `spicy`، `raw` باشد.
- `allergens` می‌تواند شامل `gluten`، `dairy`، `nuts`، `fish`، `shellfish`، `sesame`، `egg`، `soy`،
  `caffeine` باشد.
- فهرست زیرشاخه‌ها در `src/data/categories.ts` است.

## ۱۱. ویرایش قیمت‌ها

هر آیتم دو قیمت دارد:

- `toman`: قیمت نمایشی به تومان (مثلاً `320000`)
- `usd`: قیمت نمایشی به دلار (مثلاً `8.9`)

در حالت فارسی قیمت تومان و در حالت انگلیسی قیمت دلار نمایش داده می‌شود.
**هیچ تبدیل ارزی انجام نمی‌شود**؛ هر دو عدد را خودتان تنظیم می‌کنید.

برای تغییر تبلیغات و بنرها: `src/data/promotions.ts`.

---

## ۱۲. ویرایش مواد اولیه

در همان آبجکت غذا:

- `ingFa`: مواد اولیهٔ فارسی، جدا شده با «،» → `'برنج، ماست، زعفران'`
- `ingEn`: مواد اولیهٔ انگلیسی، جدا شده با کاما → `'Rice, yogurt, saffron'`

---

## ۱۳. تغییر ترجمه‌ها (متن‌های سایت)

همهٔ متن‌های رابط کاربری در یک فایل است:

```
src/i18n/translations.ts
```

هر کلید دو نسخه دارد: `fa` (فارسی) و `en` (انگلیسی). اگر متنی را تغییر دهید، حتماً نسخهٔ
دیگر زبان را هم تغییر دهید (TypeScript اجازه نمی‌دهد کلیدی جا بیفتد).

متن‌های مربوط به غذاها (نام و توضیح) در فایل‌های `src/data/*.ts` هستند، نه در فایل ترجمه.

---

## ۱۴. تغییر نام رستوران، شعار و اطلاعات نمایشی

فقط یک فایل:

```
src/config/brand.ts
```

- `name` و `latinName`: نام برند
- `tagline`: شعار
- `designer`: نام طراح — **همیشه لاتین `Nila` باقی می‌ماند**
- `creditHeader` / `creditFooter`: متن اعتبار طراحی در هدر و فوتر
- `demo`: تلفن، ایمیل، آدرس و ساعت کاری نمایشی
- `socials`: شبکه‌های اجتماعی نمایشی

> نام طراح در همه‌جای پروژه از همین فایل خوانده می‌شود و به فارسی ترجمه نمی‌شود.

---

## ۱۵. تغییر رنگ‌ها

فایل `src/styles/global.css`، بالای فایل، بخش `:root`:

```css
--orange: #ff6b00;      /* رنگ اصلی دکمه‌ها و تأکیدها */
--red: #e53935;         /* بنرهای تبلیغاتی */
--yellow: #ffc928;      /* برچسب قیمت و تخفیف */
--black: #111111;       /* بخش‌های تیره */
--white: #ffffff;       /* بخش‌های روشن */
```

فقط همین متغیرها را عوض کنید تا کل سایت هماهنگ بماند.

## ۱۶. ساختار پوشه‌ها

```
public/
  images/            همهٔ تصاویر (hero، categories، iranian، fast-food، seafood، sushi، drinks، promotions، gallery)
src/
  components/        کامپوننت‌های رابط کاربری (هدر، بنر، کارت غذا، مودال، فیلتر، فوتر …)
  config/            brand.ts (برند) و images.ts (همهٔ مسیرهای تصویر)
  data/              داده‌های منو، دسته‌ها و تبلیغات
  hooks/             (در صورت نیاز) هوک‌های سفارشی
  i18n/              دیکشنری ترجمه و مدیریت زبان
  pages/             HomePage، MenuPage، DemoPurchasePage، NotFoundPage
  styles/            global.css، layout.css، components.css، sections.css
  utils/             formatPrice.ts (قالب‌بندی قیمت)
  App.tsx            مسیرها
  main.tsx           نقطهٔ شروع برنامه
IMAGE_GUIDE.md       راهنمای جایگزینی تصاویر
README.md            همین فایل
```

## ۱۸. خطاهای رایج و راه‌حل

| مشکل | راه‌حل |
| --- | --- |
| `'npm' is not recognized` | Node.js نصب نیست یا ترمینال را بعد از نصب نبسته‌اید. VS Code را ببندید و دوباره باز کنید. |
| `Port 3000 is already in use` | یک سرور دیگر در حال اجراست. آن ترمینال را با `Ctrl+C` ببندید یا پورت را در `vite.config.ts` تغییر دهید. |
| صفحه سفید است | ترمینال را ببینید؛ معمولاً یک خطای TypeScript نوشته شده است. `npm run typecheck` را اجرا کنید. |
| تصاویر نمایش داده نمی‌شوند | نام فایل و پسوند (`.jpg`) و مسیر پوشه را چک کنید. تا وقتی فایل نباشد، قاب جایگزین با نام فایل نمایش داده می‌شود. |
| فونت فارسی درست نیست | اتصال اینترنت لازم است (فونت‌ها از Google Fonts بارگذاری می‌شوند). |
| `npm install` خطا می‌دهد | اتصال اینترنت را بررسی کنید و دوباره اجرا کنید. |
| تغییرات دیده نمی‌شوند | صفحه را رفرش کنید؛ اگر باز هم نشد، سرور را ببندید و `npm run dev` را دوباره اجرا کنید. |

---

## ۱۹. دربارهٔ تصاویر و محتوای این نمونه‌کار

- هیچ عکس واقعی در پروژه قرار داده نشده است، چون تصویر نامرتبط یا بی‌کیفیت بدتر از
  جای خالی است. هر جای تصویر یک قاب طراحی‌شده با **نام دقیق فایل** نشان می‌دهد.
- هیچ نظر مشتری، امتیاز یا آمار واقعی وارد نشده است. بخش «مفهوم پروژه» جای
  نظرات مشتریان را گرفته و آمارها دربارهٔ خودِ همین نمونه‌کار هستند.
- هیچ درگاه پرداخت، پایگاه داده یا کلید API لازم نیست. پروژه کاملاً محلی اجرا می‌شود.
